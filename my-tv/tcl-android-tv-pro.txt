# TCL "Android TV Pro", Android TV 11 (India): what my-tv/setup_tv.py disables.
# Not yet tried on this exact set. It is the part of the TCL 55P638 list (examples/tcl-55p638, same
# Android TV 11 platform, reboot-checked) that matches this owner's choices, plus packages that most of
# the 24 TCL Android TV 11 lists in examples/ disable. setup_tv.py keeps only the lines that are
# installed and enabled on the TV, so a package this set doesn't ship is skipped.
#
# Apply: python3 my-tv/setup_tv.py (or: TV_HOST=<tv ip> tools/disable.sh my-tv/tcl-android-tv-pro.txt)
# Restore: python3 my-tv/setup_tv.py restore (or: TV_HOST=<tv ip> tools/restore.sh my-tv/tcl-android-tv-pro.txt)
# Everything is DISABLED, not uninstalled.
#
# Kept on purpose, so never listed here: Netflix, YouTube, Prime Video, JioHotstar, Sony LIV, Zee5;
# Chromecast (com.google.android.apps.mediashell); firmware updates (com.tcl.versionUpdateApp,
# com.tcl.rc.ota, com.tcl.ttvs, com.tcl.UpdatePeripheral); Live TV and the tuner (com.tcl.tv,
# com.tcl.tvinput, MediaTek TV services); TCL Channel and TCL TV+ (com.tcl.channelplus,
# com.tcl.tv.tclchannel, com.tcl.waterfall.overseas, com.tcl.tv.plus); Google Assistant and the remote's
# mic (com.google.android.katniss, com.google.android.tv.assistant, com.tcl.assistant, com.tcl.micmanager,
# com.google.android.tv.remote.service); the screensaver (com.google.android.apps.tv.dreamx,
# com.google.android.backdrop); Settings and the Settings key (com.android.tv.settings, com.tcl.settings,
# com.tcl.dashboard); the remote and keyboard (com.tcl.keyhelp, com.tcl.autopair,
# com.tcl.tcl_bt_rcu_service, the keyboard in use); USB media, MagiConnect, Miracast, T-Solo, the
# gallery; Play Store and Play services.
